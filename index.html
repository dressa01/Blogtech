Apresentação

Por: Andressa Vitória

Eai, pessoal!, como Monitora de Educação Física e uma pessoa que gosta muito de voleibol, trouxe por aqui um breve resumo sobre os 4 principais movimentos do volei. Espero que goste!

MANCHETE

(Toque com o antebraço)

A manchete é o fundamento do voleibol usado para recepcionar saques ou defender cortadas. Ela é executada unindo as mãos com os braços bem estendidos e joelhos flexionados, usando a parte interna dos antebraços para amortecer e direcionar. a bola ao levantador.

SAQUE

(Saque flutuante)

O saque flutuante é aquele saque sem rotação que balança no ar e muda de direção de surpresa. Ele é feito dando um golpe seco no meio da bola, o que faz com que ela flutue e fique super difícil de a defesa adivinhar onde vai cair.

JS

(JavaScript)

É a linguagem de programação que traz interatividade e dinamismo para as páginas web. Enquanto o HTML cria a estrutura e o CSS estiliza, o JavaScript funciona como o "sistema nervoso", permitindo criar animações, menus interativos, validar formulários e atualizar dados em tempo real sem recarregar a página.

PY

(Python)

É uma linguagem de programação genérica, muito popular por sua sintaxe simples e fácil de ler. Ela é amplamente utilizada fora do navegador, servindo para desenvolvimento de sistemas web (backend), automação de tarefas, inteligência artificial, análise de dados e criação de jogos.
